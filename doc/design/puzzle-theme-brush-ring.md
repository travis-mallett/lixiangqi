# Puzzle theme icon background

`public/images/puzzle-themes/brush-ring.webp` is original AI-generated LiXiangQi artwork created with the built-in image generation tool. The 512 × 512 lossless WebP preserves the generated transparency.

The puzzle theme stylesheet uses it as an alpha mask tinted with the shared dimmed text color at 24% opacity. The texture is confined to the icon area; the existing icon files are rendered separately. There is no image background on the rest of the card.

## Generation prompt

Create ONE standalone transparent texture asset for a website icon backdrop: an expressive East Asian dry-brush ink ring / ensō, with several overlapping circular brush sweeps, tapered irregular ends, fine broken bristle streaks and worn organic gaps. Square composition, centered round shape filling about 92% of the canvas. Open transparent center and fully transparent outside; real alpha transparency, no checkerboard or white background. Flat monochrome opaque charcoal ink with naturally semitransparent dry-brush edge details. The ring should have a broad irregular brush band, not a geometrically smooth circle, and no solid filled disk. This will be used as a CSS alpha mask behind existing xiangqi icons and cropped slightly at the top and bottom of a horizontal card. Generate only the brush ring: absolutely NO icons, chess pieces, weapons, people, scenery, text, UI, card, drop shadow, lighting, metallic effect or border. The shape should read as a subtle painterly swirl when rendered at 150px. Output the isolated transparent asset.
