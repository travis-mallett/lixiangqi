# Local calibration data

This directory is intentionally excluded from version control except for this
file. The calibration tool writes databases, recovered games, screenshots,
diagnostics, backups, and generated profile exports here.

These artifacts may contain machine-specific paths and large experimental data.
They are not required to run the Lixiangqi site or its production Pikafish
worker. Preserve or archive them outside Git when an experiment must remain
reproducible.
