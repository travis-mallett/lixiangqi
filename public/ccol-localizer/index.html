A private publishing tool

Helping more people learn Xiangqi.

Chinese Chess Out Loud Localizer helps Travis Mallett prepare and publish subtitles, translated video titles, and complete translated descriptions for the Chinese Chess Out Loud YouTube channel.

This website provides information about the application. The helper runs privately on its owner's computer. Visitors cannot sign in, run it, or access the channel through these pages.

What the application does

  1. Prepares an edited English subtitle track for review, preserving the original timing.
  2. Uses OpenAI to translate and review subtitles and video metadata in selected languages.
  3. Uses YouTube API Services to publish approved English captions, translated captions, and localized titles and descriptions to the owner's selected videos.

The owner controls which videos and languages are processed and can review the generated files before publication. The tool checks that a selected video belongs to the authorized channel.

Why Google authorization is needed

Google OAuth allows the application to read the channel and video information needed for localization and upload or update captions and video metadata. YouTube requires a broad management permission for caption uploads; this helper uses that permission for the publishing functions described here.

Authorization takes place on Google's website. The helper does not collect Google passwords. Its saved Google authorization is encrypted on the owner's Windows computer and is not hosted on this website.
