# Board animation contributor instructions

Before creating, processing, replacing, or integrating a board animation, read
[`WORKFLOW.md`](WORKFLOW.md) completely. Treat it as the canonical Lixiangqi
workflow for reference analysis, Veo prompting, chroma-key cleanup, timing,
quality assurance, asset packaging, and application integration.

Preserve the event glyphs and directory contract documented there. Keep asset
timing baked into the animated WebP rather than adding playback-speed logic to
the application. Update the workflow only when a verified production lesson or
repository convention changes.
