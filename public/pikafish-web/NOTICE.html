Pikafish on LiXiangQi

LiXiangQi uses Pikafish, a xiangqi engine derived from Stockfish, with the full official neural network.

This browser build is based on Pikafish 2026-09-06, commit 4c17cee11f888ae1d48a9494f2e2239f019f0a1f. LiXiangQi contributors modified its browser loading and UCI bridge on November 1, 2026. It is not an unmodified upstream binary.
